演示控制

这里的按钮模拟手表、网络和后端，不属于 App 界面。演示账号 demo / 123456，数据只在本页内存里，刷新即重置。

App
事件
    Must 用户故事走查
    REQ-IOS-001 注册与登录
    错误密码 → 提示；用 demo 注册 → 用户名已被使用；新用户名注册直接进入；「杀掉并重新打开」不用再登录。
    REQ-IOS-002 退出与登录失效
    设置 → 退出登录，有待上传时提示条数；重新登录 demo 记录都在并继续上传；换账号只看到自己的记录。「让登录失效」后改一条记录 → 横幅「重新登录」。
    REQ-IOS-003 接收手表的训练
    「手表发来一组」→ 今天出现训练，来源「自动计次」；「重复发送上一组」不新增；断网照常保存；未登录时不保存，登录后补发。
    REQ-IOS-004 手动添加
    今天 → 手动记录一次训练；次数填 0、-1、2.5 → 提示；重量可空，填负数提示。
    REQ-IOS-005 训练详情
    点任一训练：时间、总组数、动作总次数、同步状态，组按动作分开列。
    REQ-IOS-006 修改
    详情点铅笔改次数、重量或动作；添加一组、删除一组；摘要与统计随之变化，状态回到待同步。
    REQ-IOS-007 删除
    详情 → 删除训练 → 确认弹窗；取消不变，确认后从历史和统计中移除。
    REQ-IOS-008 历史列表
    历史页按开始时间倒序、按天分组；新账号显示空状态；断网照常显示。
    REQ-IOS-009 基础统计
    今天页近 7 天统计卡；历史页近 7 天 / 近 30 天 / 全部。
    REQ-IOS-011 同步状态
    待同步 / 已同步 / 同步失败三态；「下一次上传失败」后改一条 → 同步失败 → 重试。
