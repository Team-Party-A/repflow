# 20 份称重餐盘的豆包识别实测

20 份餐盘均返回了可编辑草稿，19 份有完整的四项营养估算。原始草稿的整餐能量平均绝对误差为 60.76 千卡。推理前标为可辨认的 40 项食材中，模型识别出了 38 项。带油酱组每餐脂肪的平均绝对误差为 6.57 克。

样本是 Nutrition5k 的 20 张食堂俯拍 RGB 图。隔离后端使用 `doubao-seed-2-1-pro-260915` 做视觉识别和每百克营养补全，模型只收到照片和应用提示。食材、克数、营养参考值和可见性标记均在调用前固定。本次测量仅生成草稿。[选样与许可](../测量说明.md) · [后端实现](https://github.com/Team-Party-A/repflow/commit/3fe624e9a5ef3b003be19992ac54529e6e9542bd)

## 耗时、调用量和费用

客户端从受理任务开始每两秒查询一次。20 餐平均用时 7.04 秒，中位数 8.03 秒，第 95 百分位为 8.06 秒（最近秩法），最长 10.08 秒。47 次通用食材查找命中食物库 4 次，命中率 8.51%。同一食材可能以不同名称或制法进入新条目，例如西兰花的多种叫法。20 餐均有未命中的通用食材，每餐各发起一次视觉调用和一次批量营养补全。

| 调用阶段 | 调用次数 | 输入 token | 其中命中方舟缓存的 token | 输出 token |
| --- | ---: | ---: | ---: | ---: |
| 图片识别 | 20 | 29,100 | 0 | 1,457 |
| 营养补全 | 20 | 3,705 | 0 | 1,882 |

按该型号公开的普通输入 6 元、缓存输入 1.2 元、输出 30 元每百万 token 估算，本轮合计 **0.2970 元**，平均 **0.01485 元/餐**。账号余额、免费额度和实际账单独立核算。正式测量前，首份样本的一次接通测试在 25.24 秒处超时，未返回用量，该次费用未知，单列在本轮之外。最终配置对指定豆包型号关闭深度思考，两次请求共用 90 秒任务时限。[方舟模型价格](https://console.volcengine.com/ark/region%3Acn-beijing/docs/model-pricing) · [逐餐用量与估算](observations-meals.csv)
