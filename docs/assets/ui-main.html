重设计提案 · 对照 PR #27

01
数字最大，其余让位
抬腕只看一眼：次数用超窄超粗字体占满屏宽，动作名、组序号退成一行小字。
02
只有一个强调色
Volt 只给两样东西：当前步骤的主操作、机器实时估计的次数。人确认过的数字一律白色（浅色模式为墨色）。
03
状态 = 图标 + 文字 + 色
琥珀色 = 还有事没做完（待核对、待传、待同步）；红色 = 失败或删除。成功不用绿色，用中性勾号，避免和 Volt 抢眼。
